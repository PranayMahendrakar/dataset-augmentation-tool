# 🔄 Dataset Augmentation Tool

Generate synthetic data to expand limited training datasets.

**Author:** Pranay M

## Features
| Module | Description |
|--------|-------------|
| Paraphrase Generator | Generate paraphrases |
| Synonym Replacer | Replace with synonyms |
| Back Translator | Back-translation augmentation |
| Noise Injector | Add controlled noise |
| Style Transformer | Transform writing style |
| Entity Swapper | Swap named entities |
| Context Expander | Expand context |
| Label Preserver | Verify label preservation |
| Quality Checker | Check augmentation quality |
| Batch Processor | Process batches |
